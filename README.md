# Expense Tracker App

A personal expense tracker app for Android.

---

## Tech Stack

- Android (Java)
- Firebase Auth (Email/Password)
- Cloud Firestore
- MPAndroidChart
- Material 3 Dark Theme

---

## Features

- Signup & Login
- Email Verification
- Forgot Password
- Dashboard with Total + Chart
- Add/Edit/Delete Expenses
- Filter by Category & Date
- Settings (Change Password, Logout, Delete Account)
- Input Validation on All Forms

1. Clone the repo
2. Open in Android Studio
3. Sync Gradle
4. Build and run

## Notes

- Currency: Pakistani Rupees (Rs.)
- Categories: Food, Transport, Shopping, Bills, Entertainment, Other
- Email verification required before login
- Firestore security rules restrict data to the authenticated user
